What it does

The whole platform, one workspace

🤖

Autonomous recon agents

Role-based agents drive the full engine — scan, tiered enumeration, HackTricks / Exploit-DB research, report — over the same tools the classic tool uses.

🕸️

BloodHound-style live map

Watch the run build in real time. Trace attack paths, shift-click any two nodes, search, filter, add notes, and box off areas with regions.

🛑

Human-gated attacks

Agents can propose any of the 3,190 catalogue actions into a checkpoint — but spray / exploit only ever runs after a human approves. No blind auto-pwn.

📚

Evidence-ranked catalog

The full decision-aid catalogue, ranked against what this run actually found — open ports, confirmed vulns, held credentials.

📝

Obsidian-ready reports

Every command, finding and attack path rolls up into a clean, exportable report — nothing hidden.

🧠

Bring your own model

The “brain” is swappable — attach your internally-hosted, OpenAI-compatible LLM. No vendor lock-in, nothing leaves your network.

🔐

RBAC + dual audit

Owner / operator / viewer roles, per-project gates, and a two-sided audit trail: what ran, and who did what.

🎯

Pivot-aware topology
