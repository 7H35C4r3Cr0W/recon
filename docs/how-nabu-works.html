How Nabu works, end to end

Two views of the same pipeline: the Overview explains what happens at each stage; the System map traces the actual files, top-down, from launch to report. Click any node for detail.

Recon-only by default — no exploitation Runs offline, no AI at runtime Every command passes a compliance gate Credentials stay masked & local
▶ Watch the demo

Click a stage on the pipeline. Downstream steps pulse to show where the flow goes. Press Tab then Enter to explore by keyboard.

Auto

Runs on one click. Read-only enumeration only — anonymous checks, banners, listings.

Shown

Pre-filled and surfaced, but you click Run. Single default-credential checks — never a list.

Opt-in

Password spraying against your own authorized target. Off by default; you enable it explicitly.

Gate

The safety checkpoint every command passes. Blocks exploitation and brute-force unless Spray mode is on.
