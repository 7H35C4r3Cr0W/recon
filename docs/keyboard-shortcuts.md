# Nabu keyboard shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New scan profile |
| `Ctrl+O` | Open scan profile |
| `Ctrl+E` | Edit project |
| `Ctrl+S` | Save profile |
| `Ctrl+,` | Preferences |
| `Ctrl+Q` | Quit |
| `F1` | Open the documentation |
| `Ctrl+Enter` | Run recon — press again (or the button) to **Stop** while it runs |
| `Ctrl+.` | Stop **all** running scans |
| `Ctrl+0` | Workspace dashboard |
| `Ctrl+1` | Recon |
| `Ctrl+2` | Exploitation |
| `Ctrl+3` | Pivot |
| `Ctrl+4` | Graph |
| `Ctrl+5` | Findings |
| `Ctrl+6` | Credentials |
| `Ctrl+7` | Notes |
| `Ctrl+8` | Report |
| `Ctrl+9` | Activity |
| `Ctrl+G` | Graph view (toggle) |
| `Ctrl+R` | Report preview (toggle) |
| `Ctrl+F` | Find — focuses the search of the current view (workspace filter · findings search · reference-pane find) |
| `Escape` | Dismiss the feedback banner (and cancel/close dialogs) |
| `Enter` | Activate the primary button in a dialog (e.g. **Ok** / **Run**) |

Primary navigation (Workspace · Recon · Graph · Findings · Credentials · Notes · Report · Activity)
is also always one click away in the left nav rail. Icon-only controls carry tooltips and accessible
names, and every focusable control shows a visible focus ring for keyboard navigation.
