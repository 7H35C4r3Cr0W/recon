Local Recon Workspace · OSCP exam-legal by default · and where it goes next

Nabu turns a scan into a plan — and could turn that plan into an agent team.

A PySide6 desktop + CLI recon orchestrator that wraps standard OSCP-allowed tools, surfaces findings in a graph, and produces clean reports — recon-first, offline, no auto-exploitation. Below: the finished tool, and the blueprint for augmenting it with an agent-to-agent system for pentesters. Three interactive views, one page.

The three views

02

The agent system at a glance

If Nabu were augmented with agent-to-agent features, this is the full cast — a small, deliberate set of agents, not one per module. The 52 recon modules and 183-service catalog are tools the agents call. Recon runs autonomously; every attack agent waits at a human gate.

▸

Why so few agents? A sane design does not spawn an agent per exploit — that is thousands of agents and no coordination. Nabu's ~3,187 catalog actions live behind 23 tools; the 20 agents decide which tool to call and when. Open the Agent Map to trace any agent to the tools it uses.
